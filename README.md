# MiniLedger

MiniLedger is a personal debt and loan tracker built to record and manage money lent to friends, monitor repayment statuses, and flag overdue balances.

Built as a full-stack assessment with:
- **Backend**: Node.js, TypeScript, Express, PostgreSQL, Prisma ORM, Zod, Jest + Supertest
- **Mobile**: React Native via Expo (TypeScript), TanStack Query, React Navigation
